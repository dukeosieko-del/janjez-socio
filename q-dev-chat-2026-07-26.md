## janjez.social — Codebase Overview

### Tech Stack
- Next.js 16 (App Router) + React 19 + TypeScript
- Supabase (Auth + Postgres DB)
- Tailwind CSS v4
- ZeptoMail (transactional email)
- Vercel deployment

---

### Architecture

**Layout pattern:** Every page wraps content in `Sidebar` + `Header` + `Footer` + `AnnouncementBanner` + `LiveTicker`. The sidebar is fixed at `lg:ml-64`.

**Auth system (dual-mode):**
- Option A: Standard Supabase email confirmation
- Option B: Custom flow — admin API creates user → ZeptoMail sends branded verification email → `/api/auth/verify-email?token=` confirms via `email_verifications` table
- `AuthContext` is the global auth state provider (user, session, profile, walletBalance, isAdmin, modal state)

---

### Database Schema (5 migrations)

| Table | Purpose |
|---|---|
| `profiles` | User profile + `wallet_balance` + `role` (admin/user) |
| `email_verifications` | Custom email verification tokens |
| `admin_tables` | Admin-specific data |
| `orders` | Service orders (status: pending/processing/completed/cancelled/failed) |
| `wallet_transactions` | Financial ledger (topup/spend/refund/bonus/adjustment via M-Pesa) |
